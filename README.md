# hxwl-12 心理咨询个案记录

会谈时间线、风险等级与干预目标记录

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5112

## 功能

- 指标看板（活跃个案 / 中高风险关注 / 本周会谈 / 目标推进），由记录实时计算
- 咨询师：新增、编辑、申请归档/撤回归档；必填项与风险等级校验，防重复提交
- 督导：查看全部记录，批准归档或退回（可填退回原因）
- 机构管理员：查看记录、添加用户、分配角色（至少保留一名管理员）
- 按咨询主题、风险等级、状态筛选，支持关键词搜索
- 保存即写入 localStorage，刷新后保留；导出当前视图为 CSV
- 三条示例数据（带「示例」标记）与「填入示例」入口保持可用，可直接在其上编辑/走审批流

> 页面右上角可切换身份，体验三种角色的权限差异。

## 数据存储

数据保存在浏览器 localStorage（键名 `hxwl12.*`），清除站点数据即恢复初始示例。
